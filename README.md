# Inventory Backend

Backend API untuk sistem manajemen inventaris internal.

## Status: Privat

Repository ini bersifat **privat** dan hanya untuk penggunaan internal. Kode, dokumentasi, dan seluruh isi repository ini **tidak untuk didistribusikan, disalin, atau digunakan di luar organisasi** tanpa izin tertulis dari pemilik proyek.

Jangan membagikan akses repository, kredensial (`.env`), atau dokumentasi API kepada pihak luar.

## Tech Stack

- Go (Fiber)
- PostgreSQL (GORM)

## Menjalankan Secara Lokal

```bash
cp .env.example .env
# sesuaikan konfigurasi di .env

go run cmd/main.go
```
